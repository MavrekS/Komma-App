# Komma-App
Aplikacija za praćenje i analizu radnih naloga omogućuje tvrtkama praćenje statusa zadataka, analizu učinka zaposlenika i odjela, automatsko generiranje izvještaja te identifikaciju zagušenja, čime se poboljšava učinkovitost i optimizira radni proces.
Server se pokreće ulaskom u folder database i pisanjem npm start.
Stranica se pokreće ulaskom u folder programa i pisanjem npm run dev.
